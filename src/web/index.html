Smart EV Intelligence & Power Grid Telemetry Platform

VoltPulse is a distributed Big Data analytics platform built to solve the simultaneous challenges of EV driver range anxiety, municipal charging infrastructure deserts, and distribution transformer overload across the Delhi-NCR & Greater Noida transit network. Powered by Apache Spark MLlib (3.5.0), Apache Kafka structured streaming, and real-world municipal charging telemetry.

🚗 EV Driver Portal

Haversine GPS proximity radar, live 8-bay port occupancy matrix, linear regression duration calculator, and highway corridor pitstop routing with Google Maps navigation.

⚡ Power Grid Dispatch

NPCL substation telemetry, 24-hr load curve comparing actual vs PySpark GBT forecast, and Indian Grid Code Clause 3D 85% transformer headroom stress alerts.

🗺️ City Infrastructure Planner

Geospatial charging desert detection, PySpark K-Means spatial clustering (k=4) for capital expenditure hub siting, and MLlib 5-model evaluation scorecard.
